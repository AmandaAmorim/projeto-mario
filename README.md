Projeto Mario - Site sobre o Personagem Mario

Este projeto foi desenvolvido durante o Intensivo do Dev em Dobro e tem como objetivo criar um site explicativo sobre o personagem Mario, um dos ícones mais famosos da Nintendo e dos jogos eletrônicos.

🚀 Sobre o Projeto
O site foi desenvolvido para fornecer informações detalhadas sobre o personagem Mario, incluindo sua história, curiosidades, jogos em que ele aparece e seu impacto na cultura pop. O projeto foi construído utilizando tecnologias modernas de desenvolvimento web.

🛠️ Tecnologias Utilizadas
HTML5: Estruturação do conteúdo do site.

CSS3: Estilização e design responsivo.

JavaScript: Interatividade e dinamismo no site.
